# 언제바껴

내 주변 횡단보도를 지도에서 찾고, 다음 초록불까지 남은 시간을 **예상**해 주는 웹앱이에요.

## 어떻게 예상하나요
- 횡단보도 위치와 데이터상 초록·빨강 시간: 전국횡단보도표준데이터 (공공데이터포털)
- 사용자가 초록불 켜지는 순간을 탭하면, 그 시각과 주기로 다음 초록불을 계산해요.
- 초록불을 두 번 연속 기록하면 실제로 잰 주기로 바꿔서 계산해요.
- 기록은 이 폰 브라우저 안에만 저장돼요. 위치도 서버로 보내지 않아요.

## 파일
- `index.html`, `style.css`, `app.js` — 앱
- `data/regions.json`, `data/rXX.json` — 신호 있는 횡단보도만 지역별로 나눈 데이터
- `manifest.json`, `icon.svg`, `sw.js` — 홈 화면에 추가했을 때 앱처럼 보이게 하는 파일

## 알아둘 점
- 지금 데이터는 다운로드 파일 한도(5만 행) 때문에 전국 일부만 들어 있어요.
- 같은 좌표에 여러 횡단보도가 묶여 등록된 곳이 많아요 (교차로 중심 좌표).
- 예상치예요. 건널 때는 반드시 실제 신호등을 보세요.
